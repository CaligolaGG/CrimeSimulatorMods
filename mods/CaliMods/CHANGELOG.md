# Changelog

## 1.0.0
- "Custom Mods" button in the pause menu to enable/disable features.
- Request item highlight: items from the computer's Item requests get a red outline (still needed) or a yellow one (request already fulfilled).
- Owned count: pickup prompts show how many undamaged copies of that item you already own, e.g. `[E] Pick up: Cheap toaster (owned:1)`. Damaged copies don't count (`MaxDamage` setting).
- Skill leaflet highlight: red outline on skill leaflets whose skill you already learned (leaflets ignore the request colors).
